IMPORTANT EXPERIMENTAL NOTE
---------------------------
These query sequences are exact 500-bp fragments extracted from the same
reference genome used as the subject. This gives known positive target
locations and is suitable for the first pipeline/debugging experiment.

It is NOT sufficient by itself to claim realistic sensitivity across
divergent homologous sequences: exact self-reference matches are an easy case.
For the sensitivity study, add independent query sequences from related
E. coli strains or create a separately labelled mutation challenge set.
Do not mix those two types of data without documenting them.

Keep the subject reference and query FASTA unchanged for all K comparisons.
Record BLASTN version, task, word_size, other parameters, runtime, hit
coordinates, identity, query coverage, and whether the known target was found.
